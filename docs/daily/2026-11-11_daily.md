# Daily Development — 2026-11-11

## Summary

Der Init-Skill teilt Auswahldialoge mit mehr als vier Optionen jetzt auf mehrere Seiten auf. Anlass: Bei der Modulauswahl waren `daily` und `semver` zu einer Option zusammengelegt worden, weil der Dialog höchstens vier Optionen pro Frage erlaubt.

## Features

### Changed

| Capability | Practical effect | Evidence |
|---|---|---|
| Skill `init`: Auswahldialoge (AskUserQuestion) haben höchstens 4 Optionen pro Frage; längere Listen werden auf mehrere Fragen (Seiten) verteilt, eine Option steht für genau ein Modul, einen Teil oder ein Dokument | `daily` und `semver` werden getrennt abgefragt und `semver` bleibt standardmäßig abgewählt; die Regel gilt auch, wenn weitere Module dazukommen | 1e76308 |

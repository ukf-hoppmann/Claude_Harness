# Daily Development — 2026-11-12

## Summary

Der Harness spricht die Memos des ToDo-Viewers (ab 0.10.0) an: Aus „Note“ (`NOTE-001`) wurde „Memo“ (`MEMO-001`), aus „Notice“ „Hint“. „Note“ bedeutet im Harness nur noch die Notiz zu einem Backlog-Item. Der Viewer kennt die alten Routen nicht mehr, deshalb war die Umstellung ein harter Schnitt. Release 0.14.0.

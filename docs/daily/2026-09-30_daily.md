# Daily Development — 2026-09-30

## Zusammenfassung

Die ToDo-Viewer-API kann jetzt den Typ eines Eintrags ändern (Epic, Story,
Task). Das Hilfsskript `backlog_api.py` kennt dafür den Befehl `retype`. Weil
das Präfix der ID der Typ ist, bekommt der Eintrag dabei eine neue ID; alle
Verweise ziehen mit. Der todo-Skill führt den Typwechsel unter „erst den
Projektverantwortlichen fragen“. Release `v0.7.5` (nicht gepusht).
